# VIGIL Studio 4.8 | Complete source + LinkedIn showcase

**Important:** This is a working research-only software project, not an authorized medical device. The Windows `.exe`, large pretrained model weights and multi-gigabyte dataset collection are not bundled. Windows execution still requires Python dependencies.

## Start here

- **Use the demo:** Run `START_SHOWCASE_WINDOWS.bat` (uses isolated synthetic research examples; does not touch your existing `VIGILStudio_Workspace`).
- **Use the standard app:** Run `START_WINDOWS.bat` (opens your usual research workspace).
- **Share on LinkedIn:** Upload `SHOWCASE/VIGIL_STUDIO_LINKEDIN_CAROUSEL.pdf` as a document/post, or use individual `SHOWCASE/linkedin_carousel/*.png` images.
- **View all 14 software sections:** Open `SHOWCASE/screenshots/`. There are actual app screenshots for all 14 sections, plus additional quality, EEG and EMG views.
- **Read reports:** `SHOWCASE/professional_synthetic_research_report.pdf`, `SHOWCASE/MITBIH_reference_annotation_report.pdf` and `SHOWCASE/professional_engineering_readiness_report.pdf`.
- **Caption:** Optional wording is in `SHOWCASE/LinkedIn_Post.txt`.
- **Data integrity and safety:** Read `SHOWCASE/DATA_SOURCES_AND_DISCLOSURES.md` and `SHOWCASE/README_SHOWCASE.md`.

## What is included (and what is not)

Includes the complete VIGIL Studio v4.8 Python source, its tests/launchers, five synthetic demonstration recordings, 20 visual references (19 actual v4.8 screenshots and one genuine MIT-BIH reference-marked ECG image), 12 LinkedIn slides, four professional PDFs including the carousel, and supporting CSV/JSON evidence examples.

Original MIT-BIH waveform binary files, hospital patient data, clinical trial results, model weights, a code-signed executable and medical-device authorization are **not** included.
